# Packet Tracer Projects

Kumpulan simulasi jaringan menggunakan Cisco Packet Tracer sebagai bagian dari pembelajaran networking.

---

## Structure

Setiap projek punya folder sendiri dengan struktur:

```
[nama-projek]/
├── docs/
│   ├── konfigurasi-cli/    ← running config per device
│   ├── notes/              ← catatan desain dan troubleshooting
│   └── screenshots/        ← tangkapan layar topologi
└── topologi/               ← file .pkt
```
